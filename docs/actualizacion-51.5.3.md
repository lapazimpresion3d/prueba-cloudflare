# 51.5.3 — Libro comercial privado (base)

COMMERCE_DB, servicio deshabilitado por defecto y sin rutas. Registro de venta y reversión total, centavos MXN, ID por empresa, sucursal obligatoria, actor autenticado. Una sentencia INSERT y trigger de auditoría forman unidad atómica; original inmutable y una reversión exacta por venta. Reintento exige mismo actor, contexto y contenido; no duplica auditoría. Revalidación SQL de sesión (hash derivado de cookie, no devuelto), membresía, permisos padre/granular, sucursal, suscripción, módulo POS y cuotas. Consulta paginada y resumen bruto/reversado/neto. No es contabilidad de partida doble ni POS completo: no catálogo de precios autorizado, turnos, inventario, anticipos, folios externos, conciliación bancaria ni devoluciones reales. El importe debe proceder de capa confiable antes de conectar rutas. No aplicar migración remota. SQLite pruebas de regresión y revocación entre autenticación y escritura; concurrencia D1 real y recuperación entre dispositivos pendientes. Política provisional: no permite revertir con contrato suspendido; requiere procedimiento administrativo futuro.
