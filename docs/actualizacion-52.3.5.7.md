# 52.3.5.7 — Interfaz, navegación y recuperación
Shell HTML adaptable con navegación por ruta, progreso de requisitos obligatorios (no visitas), pausa/reanudación, formularios de datos básicos, colores, presentación, contacto, horario, alta/edición de sucursal y principal. Contacto/horario y secciones usan JSON editable; imágenes no se editan todavía. Personal, roles, servicios, recursos y módulos son consulta guiada, sin formularios de edición especializados. Checklist, registro e historial de validación. Controlador HTTP candidato con opt-in explícito, HTTPS, origen POST, allowlist, límite JSON, control de sesión y propietario del asistente antes de delegar, CSP nonce, no-store, sin almacenamiento local. No se monta en worker-comercial ni en demos: no hay URL desplegada. Los errores ocultan detalles internos y exigen recuperar estado, sin reintento automático de escrituras; se descarta formulario no confirmado y se recarga dato persistido, no hay borradores offline ni recuperación de contraseña. Pruebas de integración HTTP con fixture SQLite/OIDC, no navegador real. Sin migración nueva, main, producción, tarifas o D1 remoto. Siguiente 52.3.5.8 pruebas integrales y cierre.
