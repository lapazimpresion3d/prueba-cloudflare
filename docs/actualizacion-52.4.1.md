# 52.4.1 — Arquitectura y navegación central privada
Candidato aislado, no montado en worker-comercial. Reutiliza acceso-central para identidad OIDC/MFA y sesiones centrales; inyección del servicio verificado obligatoria. Rutas GET /interno/central, GET /interno/central/navegacion, POST /interno/central/salir. Cerradas por defecto, origen HTTPS exacto, método y Origin POST, no-store, CSP nonce, sin datos embebidos ni almacenamiento local. Navegación accesible y adaptable: inicio activo, siete secciones pendientes sin enlaces operativos. Cierre de sesión delega al acceso central; autenticación reciente POST del servicio existente puede requerir nueva autenticación antes de cerrar (pendiente mejorar en 52.4.8). No monta login OIDC ni rutas de datos reales. Pruebas unitarias con acceso simulado, no validación real de MFA o navegador. No modifica main, demos, precios, contratos ni bases remotas. Próximo 52.4.2 indicadores, distinguir registros de pagos de ingresos reales y no duplicar sistema económico principal. 52.S después de cerrar 52.4.
