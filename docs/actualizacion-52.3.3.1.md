# 52.3.3.1 — Perfil comercial persistente
Amplía comercio_perfiles_privados con descripción, lema y fecha de actualización. Nombre público editable independiente de empresas.nombre; giro e identidad inmutables. Servicio interno consultar/guardar, solo propietario de alcance empresa con permisos empresa.ver/administrar y sesión comercial revalidada dentro de escritura, alta verificada e implementación pendiente/configuracion/revision; bloquea suspendidas/canceladas. Se permite antes de contratar; no concede módulos. CAS y auditoría atómica sin copiar texto en log. Campos de texto plano (futura interfaz debe escapar al renderizar); no HTML interpretado, identidad visual, horarios, contacto ni publicación. Migración 0027 no aplicada remotamente. Prueba integral OIDC de dos empresas, concurrencia, CSRF, identidad, revocación y aislamiento. Sin rutas, precios, demos, Logto ni producción.
