# 52.3 — Alta autorizada y configuración inicial (primer bloque)
Servicio interno deshabilitado por defecto. Operador central prepara alta con sesión central reciente revalidada dentro de SQL, plan/version existente, giro, nombre, sucursal y emisor+sujeto del futuro propietario. No se acepta correo como identidad. Solicitud dura 24h, aceptación única vinculada a identidad verificada por callback confiable; requiere operador aún activo. Batch crea empresa, primera sucursal, roles base, propietario, perfil privado, implementación en configuración y auditorías; rollback si propietario desactivado. No crea contrato ni activa módulos automáticamente; plan/version queda como intención de contratación. No se cambian tarifas. Giro otro genérico, color inicial neutro. No rutas, no entrega ni comunicaciones. El servicio histórico registrar permanece aislado y no debe exponerse. Falta flujo OIDC de propósito alta con consumo único, registro seguro de identidad del prospecto, cancelación/renovación de altas, idempotencia de preparación, contratación y validación de módulos por giro, editor visual, checklist de entrega, suspensión/reactivación, pruebas remotas. Migración 0018 solo COMMERCE_DB, no aplicada remotamente.
