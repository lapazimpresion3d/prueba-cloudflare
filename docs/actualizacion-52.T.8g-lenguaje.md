# 52.T.8g.5 — Lenguaje comercial
Se simplifican títulos, acciones, indicadores y mensajes visibles en módulos turísticos y generales mediante sustituciones explícitas, sin modificar códigos de estado, lógica operativa, almacenamiento, permisos ni contratos. Se mantienen advertencias de demostración, datos de ejemplo, ausencia de cobros reales, integraciones simuladas y documentos sin validez fiscal. La bolsa de minutos queda para 52.S.3b. No se modifica el administrador central. La revisión no pretende eliminar todas las menciones de práctica: se conservan cuando describen límites o consecuencias. Pendiente validación integral y revisión pública.
