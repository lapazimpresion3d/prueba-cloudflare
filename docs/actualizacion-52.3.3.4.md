# 52.3.3.4 — Contacto privado y proyección de visibilidad
Migración 0030 añade JSON de contacto al perfil existente, revisión compartida. Teléfono y WhatsApp internacionales (+ código país), correo, dirección, par de coordenadas, enlace Maps, sitio HTTPS, Facebook/Instagram/TikTok/YouTube/LinkedIn/X; modalidades establecimiento/domicilio/en línea. Visibilidad individual desactivada por defecto; proyección explícita sin campos ocultos, enlaces tel/wa.me/mailto/Maps generados sin llamadas externas. Redes y Maps restringidos por hostname y rutas básicas; no verificar propiedad, redirecciones finales ni existencia de destino. Sitios HTTPS son enlaces externos no confiables: futura interfaz debe escapar texto, usar rel=noopener noreferrer y no hacer fetch servidor. Guardado reemplaza contacto completo; campos omitidos se vacían y visibilidad omitida se desactiva. Modalidades son parte de proyección, no habilitan módulos. No importar identidad OIDC ni datos de empleados. Autorización propietaria, sesión, CAS, auditoría sin PII. No publicación ni rutas; vista previa interna solamente. Coordenadas opcionales, introducidas por comercio, no geolocalización automática. Migración remota/D1 real pendientes; no precios, demos, main ni producción.
