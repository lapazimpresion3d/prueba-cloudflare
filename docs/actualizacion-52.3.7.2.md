# 52.3.7.2 — Suspensión temporal y restricciones de acceso
Servicio interno suspender POST con sesión central reciente, origen, motivo, revisión y contrato verificado. Migración 0043 añade corte por empresa/usuario atómico con transición. No revoca sesión global ni modifica membresías. Núcleo deniega suspendida/cancelada; selector omite comercios suspendidos; libro revalida corte dentro de SQL. Administración legado excluye altas verificadas. Los servicios privados de configuración conservan sus propios guardas. Reactivación y cancelación siguen sin métodos públicos. No se monta HTTP ni se aplica migración remota. Pendiente auditoría exhaustiva de guardas de escritura concurrentes, nuevas sesiones durante suspensión, reactivación, cancelación, navegador y D1 real. Pruebas OIDC/SQLite de suspensión, rechazo de duplicado, corte selectivo, identidad compartida y conservación de perfil.
