# 52.3.7.4 — Cancelación y baja comercial
Servicio interno cancelar POST con sesión central reciente, origen, motivo y revisión contractual; confirmación exacta CANCELAR:<empresa>:<revision>, sin token secreto ni efecto automático. Permite terminar suscripción activa, prueba o suspendida, incluida vigencia vencida/programada. Migración 0045: corte selectivo en la misma transacción, cancelación de invitaciones laborales pendientes y protección terminal de suscripción y activación de contratos verificados. Conserva empresa, usuarios, membresías, datos, selección y registros financieros. No revoca sesiones globales. No borra ni anonimiza información, no realiza devolución, cobro ni nueva contratación; baja administrativa significa fin del servicio, no baja fiscal. Pruebas fixture OIDC/SQLite para confirmación, autorización, revisión, cancelación positiva, duplicado, bloqueo de reactivación y escritura directa, datos y acceso a segundo comercio. Pendiente prueba específica de invitaciones pendientes, exportación, conservación, auditoría concurrente, UI y D1 remoto. Sin despliegue. Siguiente 52.3.7.5 conservación y exportación.
