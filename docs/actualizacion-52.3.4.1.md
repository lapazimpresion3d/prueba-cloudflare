# 52.3.4.1 — Sucursales persistentes
Reutiliza sucursales y claves compuestas; migración 0032 agrega revisión, contacto y horario JSON opcionales (null hereda el conjunto de empresa, no por campo). Principal en tabla única por empresa, CAS separado, activa obligatoria; migración selecciona menor ID activo para registros previos (no implica orden histórico), primera sucursal nueva se asigna automáticamente. Cambiar principal antes de desactivar; no borrar sucursales. Servicio interno verificado por propietario/sesión/alta/implementación, consultas paginadas incluidas inactivas, CAS y auditoría atómica sin PII; límite activo de suscripción vigente o 1 sin ella. Bloquea escritor legado para altas verificadas. Horario/contacto validados, herencia representada por null; resolución efectiva y publicación por sucursal pendientes. No activa módulos ni modifica personal. Pruebas de dos empresas, P2/P3, concurrencia, principal, baja lógica y sesión. Sin rutas, D1 remoto, main, precios ni demos.
