# 52.3.4.3 — Roles operativos versionados
Catálogo explícito de acciones por módulo, plantillas sugeridas sin concesión automática. Roles operativo- independientes de roles legacy; base empresa.ver únicamente. Políticas y restricciones individuales append-only, CAS y auditoría. Guardado propietario verificado; módulos de política deben pertenecer al contrato, ejecución verifica sesión, sucursal, membresía, vigencia, límites, activación, compatibilidad y dependencias técnicas, denegaciones individuales y legacy. Autorizador nuevo para futuras rutas, no reemplaza autorizadores existentes ni otorga permisos legacy. Las plantillas son sugerencias reutilizables, no se instalan por giro automáticamente; asignación real y consulta de historial administrativo se completarán en 52.3.4.4/7. Pruebas OIDC/SQLite con asignación directa de fixture. No rutas, migraciones remotas, cambios de precios, main o demos.
