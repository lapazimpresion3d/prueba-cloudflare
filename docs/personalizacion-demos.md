# Personalización visual y perfiles de práctica en servidor
## Alcance
Cuatro portadas ilustradas originales para cafetería, barbería, tienda de mascotas y taller. El Comal conserva su imagen existente. No son fotografías reales. El panel de información permite seleccionar logo y portada desde JPG, PNG o WebP de hasta 8 MB; navegador decodifica y reexporta JPEG, máximo 320 px de lado mayor para logo y 1000 px para portada, con reducción adaptativa a 100000 caracteres de data URL por imagen. Fondo blanco para transparencias. Se descartan metadatos del original al reexportar. El servidor valida formato de transporte, prefijo y tamaño, no realiza decodificación completa de imágenes. No admite URL externa, SVG subido ni HTML. Mantener fotografías ficticias; no introducir datos personales. Las fotografías individuales de productos y los medios de clientes reales siguen pendientes.
El visitante normal ve solo la semilla y arte original. El panel aplica cambios en su copia local; "Ver mi página de práctica" usa practica=1 explícito y no comparte cambios por URL. Puede activar sesión, recuperar identidad y guardar en servidor con revisión. Guardar identidad guarda la última personalización aplicada, no campos sin aplicar. Los catálogos remotos siguen en el laboratorio; perfil remoto no es una cuenta SaaS ni publicación real. El guardado remoto permanece opcional.

## Migración incremental (pendiente)
Aplicar solamente en Cloudflare D1 lapaz-demos-desarrollo, ID 89b84ed2-10be-42ce-9933-869675a5f009, binding DEMO_DB. Abrir Console, ejecutar migrations-demo/0002_perfiles.sql. No tocar el-comal-disponibilidad. CREATE TABLE IF NOT EXISTS; no altera tablas previas. Consultar SELECT name FROM sqlite_master WHERE type='table' AND name='demo_perfiles'; debe aparecer demo_perfiles.
GET /api/demo/contexto informa perfilConfigurado (true cuando existe esquema previo y tabla); persistenciaConfigurada sigue indicando catálogo. Si falta la tabla de perfiles, se conserva catálogo remoto existente y edición local. No cambiar secreto ni bindings.
GET/PUT /api/demo/perfil?negocio=...&plan=...: requiere sesión temporal vigente, contexto y web disponible, origen exacto en PUT, validación, límite JSON 220000 bytes. Tabla con PK sesión/establecimiento, FK ON DELETE CASCADE, revisión optimista y caducidad. Conflicto 409. No escribir datos de negocio reales. El nuevo perfil se recupera explícitamente, no de forma automática. No sincronización entre dispositivos. Copia remota expira a las 2 h; limpieza oportunista anterior se mantiene.
