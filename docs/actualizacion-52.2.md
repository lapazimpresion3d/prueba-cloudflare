# 52.2 — Identidad externa: primer bloque
Se incorpora verificador criptográfico de ID tokens OIDC RS256 con Web Crypto. Emisor HTTPS, audiencia única, claves públicas de confianza configuradas por servidor, kid único, firma, nonce esperado, correo verificado, tiempos de emisión/autenticación/expiración y ACR configurado para acceso central. Ventana provisional de autenticación reciente 5 minutos, tolerancia futura iat 30 segundos, máximo de vida del token 1 hora. No obtiene claves desde URLs indicadas por el token. No conserva token ni devuelve claims arbitrarios. Pruebas con clave RSA generada localmente.
No es flujo OIDC completo: falta seleccionar proveedor, discovery/JWKS y rotación, autorización code + PKCE, state y nonce aleatorios almacenados y consumidos atómicamente, intercambio de código, protección de replay, rate limits y vinculación con sesiones. El nonce recibido por el verificador debe provenir exclusivamente del servidor; no se autoriza reutilizar un token ni utilizar un nonce del cliente. ACR solo acredita MFA si el proveedor contratado garantiza su significado. Aún no conectado a altas, sesiones o administrador central; no hay operador real identificado ni login habilitado. Recuperación de acceso delegada al proveedor, pendiente implementación y pruebas: no reset local, no bypass por correo, preservar identidad emisor+sujeto, revocar sesiones tras recuperación y verificar titularidad con procedimiento administrativo si cambia identidad. Worker 52.1 sigue cerrado, no hay secretos ni recursos remotos configurados. Sin migraciones ni pagos/comunicaciones reales.
