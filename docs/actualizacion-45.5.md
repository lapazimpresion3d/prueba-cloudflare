# 45.5 · Auditoría de usabilidad (revisión estática y pruebas)
Hallazgos corregidos: terminales ausentes del inicio pero presentes en navegación; cambio de ancho móvil ocultaba menú al volver a escritorio; rutas index.html no reconocidas; compras, recetas y comprobantes ignoraban selección de sucursal y empleado; POS descartaba carrito al cambiar sucursal sin confirmar, y cancelación no refrescaba estado de venta; CSS de impresión size ancho+auto inválido. Se añadió aviso de salida con venta pendiente (sujeto al navegador), tamaños táctiles y control de desbordamiento. Impresión usa papel elegido por usuario/driver; no se verificó impresora física. Pruebas de aislamiento con dos almacenamientos independientes, no prueba de penetración ni prueba E2E. Pendientes: validación visual real escritorio/móvil, formularios completos, integración local/servidor, sincronización de flujos y seguridad comercial. Sin cambios a main ni migraciones.
