# 51.5.2 — Conciliación de anticipos de práctica

Los anticipos existentes no contienen método ni turno; se tratan como registros externos ficticios, no efectivo de caja. Conversión de orden terminada conserva total comercial y fotografía de anticipos activos, registra solo saldo en turno, permite saldo cero, conserva inventario y vinculación en mismo guardado. Referencias de anticipos y ventas no se reutilizan en nuevas ventas; reintento de anticipo idéntico no duplica, anulación previa idempotente. Conversión repetida con mismo ID y condiciones recupera venta. Comprobantes y caja distinguen anticipos previos del cobro de turno. Reporte de ventas sigue mostrando importe comercial, no flujo de caja. No se permite anular venta de orden convertida ni anticipo aplicado; requiere flujo compensatorio especializado. No se modifica motor de cuentas múltiples ni se concilian depósitos históricos reales. No hay recuperación persistente del ID UI tras recarga; no concurrencia entre dispositivos ni cobro real. Sin migraciones remotas. Pruebas CI pendientes.
