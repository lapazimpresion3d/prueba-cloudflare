# 51.6 — Validación y privacidad: primer bloque

Validador JSON compartido limita profundidad a 32 y nodos a 30000; rechaza claves de prototipo y números no finitos. Se conserva límite UTF-8 existente y compatibilidad escalar. Worker público candidato devuelve errores controlados y no expone excepciones inesperadas. Directorio local reconstruye identidades ficticias desde catálogo/posición y proyecta solo campos permitidos, no confía en datos personales almacenados; no borra automáticamente el contenido previo de storage hasta una escritura válida. CSV común refuerza neutralización de fórmulas, incluidos prefijos invisibles y variantes de ancho completo. Pruebas negativas. Pendiente validación de esquema de cada ruta, revisión de sinks XSS, validación estructural de JPEG y archivos, inventario de datos privados, retención/borrado, diagnóstico seguro y revisión de exportaciones no compartidas. No se afirma cumplimiento legal ni seguridad completa. Sin migraciones ni rutas privadas activadas.
