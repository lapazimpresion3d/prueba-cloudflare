# 52.3.3.5 — Presentación y publicaciones internas
Migración 0031: configuración de estilo clásico/compacto, orden y visibilidad de descripción, horario y contacto; vista previa explícita sin datos privados. Instantáneas inmutables con secuencia por empresa, autor, revisión del borrador y referencia de restauración. Publicar requiere propietario autorizado, sesión revalidada, implementación en configuración/revisión, web técnicamente habilitada por servidor y contratada/activada, vigencia y límites. Doble CAS de borrador y versión publicada. Restauración crea nueva versión sin editar borrador ni reactivar contactos históricos: usa únicamente la proyección de contacto actual si ambas versiones permiten sección. Historial paginado privado; consulta privada de versión vigente/histórica. No publicación HTTP, HTML, dominio, CDN, despliegue o acceso anónimo. Datos históricos de contacto que fueron visibles siguen privados en instantáneas; política de retención/redacción pendiente 52.8. No validación completa de contraste/decodificación de imágenes ni render navegador. No se cambia estado de implementación ni se activa web automáticamente. D1 real pendiente.
