# Fotografías de catálogo y administración de práctica (v0.7)
## Funcionalidad
En el panel de demostración, Catálogo → Agregar elemento o Editar → Foto del producto o servicio. Seleccionar JPG, PNG o WebP hasta 8 MB. Se reexporta en el navegador a JPEG con fondo blanco, lado mayor inicialmente hasta 640 px y máximo 45000 caracteres de data URL; se reduce calidad/tamaño para ajustarse. Guardar elemento aplica a la copia local. Quitar foto y guardar conserva la eliminación explícita al recargar o recuperar desde servidor. Restaurar catálogo recupera las imágenes de semilla.
La vista de práctica muestra estas fotos; la página pública limpia no consulta cambios. Para guardar en D1, activar sesión y guardar catálogo; si existe revisión previa, recuperar antes de guardar. El panel ofrece estos botones con lenguaje comercial; el laboratorio conserva acceso. La copia temporal caduca a las dos horas. No publicar información real o personal. Se conserva el control de revisión y aislamiento por sesión/establecimiento.
## Límites
Se reutiliza demo_catalogos sin migración adicional. Máximo 100 elementos y 300000 bytes UTF-8 por catálogo (incluidas imágenes). El límite agregado es deliberado: no es alojamiento profesional de medios. Se rechazan URL externas, SVG y rutas estáticas ajenas a la semilla; validación del formato de transporte, no decodificación completa en servidor. Los originales no se envían. Los cambios que superarían el límite no sustituyen la copia previa. Almacenamiento local bloqueado o sin cuota mantiene el borrador en memoria con aviso.
